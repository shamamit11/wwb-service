# Skill: Livewire Frontend

## Use When

- working in the public frontend
- changing reader-facing pages or interactive components
- improving content rendering or blog discovery flows
- adjusting frontend SEO presentation

## Expected Area

Primary path is `fe/` when that repository or folder is available.

## Context To Load

- `.agent/PROJECT-CONTEXT.md`
- `.agent/ARCHITECTURE.md`
- `.agent/COMMANDS.md`
- `.agent/skills/seo.md`
- `.agent/skills/testing.md`

## Working Rules

- Expose only approved and publishable content states.
- Keep frontend behavior aligned with SEO and performance goals.
- Prefer reusable Livewire patterns over page-specific hacks.
- Document any dependency on backend content state or routing assumptions.
