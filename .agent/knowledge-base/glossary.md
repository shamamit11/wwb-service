# Glossary

- Wide Web Blog: the overall AI-assisted blogging platform
- Backend/API: Laravel application layer for business logic and integrations
- Admin: internal editorial interface built with Laravel, Livewire, and shadcn UI
- Frontend: public blog experience built with Laravel, Livewire, and Tailwind
- Media service: storage and retrieval flows for uploaded assets using Cloudflare R2
- AI content engine: workflow area for topic discovery, draft creation, SEO generation, and future image generation
- Draft: content not yet approved for publishing
- Approved: content explicitly cleared by admin for publishing flow
