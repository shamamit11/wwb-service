# Local Agent Workspace

This folder is owned by the repository and may evolve over time.
The initial scaffold was generated from EKA standards and then written locally by the agent.

## Current Standard

- Repository: this repository
- Matched scaffold standard: General Repository
- Scaffold mode: one-time bootstrap

## How To Use

1. Read `eka.md` first.
2. Read the template-specific rules in this folder before making code changes.
3. Extend these files locally when the repository needs more explicit instructions.

## Repository Question Default

- Use EKA MCP first for repository context, indexed code questions, architecture, endpoints, and cross-repository understanding.
- Use local repository files when the question depends on the current workspace state, uncommitted changes, or when EKA evidence is missing, stale, or ambiguous.
- When falling back from EKA to local files, say so explicitly.

## Ownership

- EKA provides the generation rules and context tools.
- This repository owns the actual local agent files after bootstrap.
